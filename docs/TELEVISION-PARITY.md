# TV release parity

The reference is the shipping Marquee webOS client (`rust-modules/screens/src`), not the handset or an earlier mock. A shared Android engine counts only when the TV remote can reach it and Back returns to the right place. Candidate controls below need an offline remote journey before release. Emulator frame timings do not establish device performance.

| LG surface | Android TV coverage | Remaining release checks or work |
| --- | --- | --- |
| Account and Home | Plex link, profile/PIN and server switching, themes and favorite libraries. Home Rows shows, hides and reorders shelves per profile, including a reset to server order | Verify account and personalization with the remote; top-bar configuration and tour |
| Library, search, collections | Paged titles, Recommended and Collections. Genre, unwatched and sort combine and persist per profile/library. Alphabetical browsing opens a letter at its filtered server offset. Search supports movies, shows, episodes and profile-specific recent searches | Verify filter restoration and search with the remote; cross-server search and display options |
| Watchlist and item menu | Movie/show filters and date-added, title, release-date or rating order in either direction include later pages. Account Watchlist resolves local copies; unmatched titles offer Requests when enabled. Movie/show menus check membership before adding or removing. Watched status, whole-series confirmation and Undo are available from the remote | Verify remote journeys against fixtures; released-only and reachable-server availability filters, other permitted item actions |
| Film, series and people | Episode details and Go to Show, Resume/Start, About with full synopsis and credits, library copies, playback by file version, cast → filmography, bonus clips, related shelves and hero trailers | Crew filmography, poster/logo treatments, dedicated trailer transport and on-device focus restoration |
| Player and transport | Tracks above the timeline; Info and Chapters below. Back cancels a seek, dismisses an offer or hides controls before leaving. Intro, marked credits, chapter jumps, seek previews, quality, speed, aspect, stop-at-end and 15/30/60-minute sleep timers | Remote screenshot and Onn acceptance; plugin HUD layouts, A/V sync and diagnostics |
| Subtitle appearance | Eight presets, six font choices, brightness and opacity, six edges, line/window background, position and inset. Text dialogue supports line spacing, edge thickness, rounded backing and padding. Settings and the player use one editor and caption renderer | Verify text, positioned signs and bitmap files separately. Android system fonts, scene blending and authored ASS rendering are not equivalent to LG's |
| Services | TV Settings hosts Seerr, Bazarr, SpeechDock and diagnostics. Requests appears only with a verified Seerr connection. The player exposes subtitle search and its result | Verify remote setup, enable/disable, request/search/status, subtitle correction and failure/permission cases. The proposed NAS discovery index stays parked |
| Platform behavior | At 1× without picture effects, the TV requests a shared hardware audio/video clock when both tracks support it. Playback Info reports active hardware sync and separates skipped frames from late drops. Onn 4K Pro, local 24000/1001 HEVC and AC3 5.1: 72 decoded and 72 presented in each three-second sample before and after seeking; no display interval exceeded 42.1 ms | Silent fixture; audible lip sync, long playback and other codecs remain unverified. LG-only Magic Remote, compositor and panel-care controls are not Android settings |

The emulator review uses an isolated fixture account and package. The local sideload package retains its original signing identity. No receipt from either is a substitute for the other.
