# TV release parity

The reference is the shipping Marquee webOS client (`rust-modules/screens/src`), not the handset or an earlier mock. A shared Android engine counts only when the TV remote can reach it and Back returns to the right place. Candidate controls below need an offline remote journey before release. Emulator frame timings do not establish device performance.

| LG surface | Android TV coverage | Remaining release checks or work |
| --- | --- | --- |
| Account and Home | Plex link code, server selection, Continue Watching and themed Home rails; Settings includes profile/PIN and server switchers, libraries and the theme gallery | Verify remote account flows using fixtures. Home and top-bar configuration; tour |
| Library, search, collections | Search keyboard; paged titles; candidate adds Recommended, Collections, Genres, Unwatched and both sort directions | Combine filters, jump by letter, remember each view, cross-server search, alternate sources, favorites, display options and empty/error states |
| Watchlist and item menu | Candidate opens a paged account Watchlist and resolves a catalogue title against the current server before offering a local copy | Add/remove and Undo, sorting, unavailable titles and requests, watched status and other permitted item actions |
| Film, series and people | Episode details and Go to Show, Resume/Start, About with full synopsis and credits, playback by file version, cast → filmography, bonus clips, related shelves and hero trailers | Alternate copies across libraries, crew filmography, poster/logo treatments, dedicated trailer transport and on-device focus restoration |
| Player and transport | Track controls above the timeline, Info and Chapters below; no remote-key legend. Back cancels a seek, dismisses an active offer or hides the controls before leaving. Intro, marked credits, chapter jumps, seek previews, quality, speed, aspect and stop-at-end | Remote screenshot and Onn acceptance; plugin HUD layouts, timed sleep, A/V sync and diagnostics |
| Subtitle appearance | Eight presets, six font choices, brightness and opacity, six edges, line/window background, position and inset. Text dialogue supports line spacing, edge thickness, rounded backing and padding. Settings and the player use one editor and caption renderer | Verify text, positioned signs and bitmap files separately. Android system fonts, scene blending and authored ASS rendering are not equivalent to LG's |
| Services | TV Settings hosts Seerr, Bazarr, SpeechDock and diagnostics. Requests appears only with a verified Seerr connection. The player exposes subtitle search and its result | Verify remote setup, enable/disable, request/search/status, subtitle correction and failure/permission cases. The proposed NAS discovery index stays parked |
| Platform behavior | Hardware decoding and Android display-rate APIs replace webOS playback services | Verify direct vs converted routes, restore display mode, focus and panel transitions on Onn. LG-only Magic Remote, native compositor and panel-care controls are not Android settings |

The emulator review uses an isolated fixture account and package. The local sideload package retains its original signing identity. No receipt from either is a substitute for the other.
