# TV release parity

The reference is the shipping Marquee webOS client (`rust-modules/screens/src`), not the handset or an earlier mock. A shared Android engine counts only when the TV remote can reach it and Back returns to the right place. Candidate controls below need an offline remote journey before release. Emulator frame timings do not establish device performance.

| LG surface | Android TV coverage | Remaining release checks or work |
| --- | --- | --- |
| Account and Home | Plex link, profile/PIN and server switching, themes and favorite libraries. The six-page remote tour runs once per profile, can be skipped, and reopens from Settings. Top Bar controls library, Search, Watchlist and enabled Requests shortcuts; Settings stays reachable. Home Rows hides and reorders shelves or restores server order | Verify account, tour and personalization with the remote |
| Library, search, collections | TV libraries list shows, seasons or episodes; each type has its own paging and alphabetical offsets. The profile remembers the listing, sort and filters. Genre applies to movies and shows. Collections and Recommended open separately. Under Posters controls captions. Search includes movies, shows, episodes, local people and recent searches. A person opens titles from the server that supplied the result | Episode grid and person filmography reached in emulator run 45965156917. Cross-server search and further display options remain |
| Watchlist and item menu | Released only uses Plex Discover’s released feed and keeps the Watchlist’s sort order; it does not guess from the date. Movie/show filters and date-added, title, release-date or rating order include later pages. Account Watchlist resolves local copies; unmatched titles offer Requests when enabled. Movie/show menus check membership before adding or removing. Watched status, whole-series confirmation and Undo are available from the remote | Verify Released with the remote; reachable-server availability and other permitted item actions remain |
| Film, series and people | Episode details and Go to Show, Resume/Start, About with full synopsis and credits, library copies, playback by file version, cast and crew filmographies, bonus clips and related shelves. Credits without IDs open only on a unique exact name for that role on the active server. Server posters show playback progress, a watched check or remaining episode count. Home and detail heroes show the title until its Plex logo is ready. Up on a playing hero trailer promotes the same session to full screen, with pause, seek, a clock and Back/Down to collapse | Cross-server credits, collection artwork and on-device focus restoration |
| Player and transport | Tracks above the timeline; Info and Chapters below. Back cancels a seek, dismisses an offer or hides controls before leaving. Intro, marked credits, chapter jumps, seek previews, quality, speed, aspect, stop-at-end and 15/30/60-minute sleep timers | Remote screenshot and Onn acceptance; plugin HUD layouts, A/V sync and diagnostics |
| Subtitle appearance | Eight presets, six font choices, brightness and opacity, six edges, line/window background, position and inset. Text dialogue supports line spacing, edge thickness, rounded backing and padding. TV dialogue moves clear of the transport; positioned text, vertical writing and bitmaps retain their decoded placement. Settings and playback use the same renderer | Review decoded cues with both anchors and transport states. File decoding, Android fonts, scene blending and full authored ASS rendering are separate from this placement check |
| Services | TV Settings hosts Seerr, Bazarr, SpeechDock and diagnostics. Requests appears only with a verified Seerr connection. The player exposes subtitle search and its result | Verify remote setup, enable/disable, request/search/status, subtitle correction and failure/permission cases. The proposed NAS discovery index stays parked |
| Platform behavior | At 1× without picture effects, the TV requests a shared hardware audio/video clock when both tracks support it. Playback Info reports active hardware sync and separates skipped frames from late drops. Onn 4K Pro, local 24000/1001 HEVC and AC3 5.1: 72 decoded and 72 presented in each three-second sample before and after seeking; no display interval exceeded 42.1 ms | Silent fixture; audible lip sync, long playback and other codecs remain unverified. LG-only Magic Remote, compositor and panel-care controls are not Android settings |

The emulator review uses an isolated fixture account and package. The local sideload package retains its original signing identity. No receipt from either is a substitute for the other.
